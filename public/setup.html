Reopen setup to continue

For your security, setup closes one hour after your Cardlake first starts, so nobody else can claim it. You can reopen it from Vercel.

How to reopen setup

  1. In Vercel, open this project, then Settings and Environment Variables.
  2. Add a variable named CARDLE_SETUP_OPEN with the value 1, and save.
  3. Open Deployments, choose the latest one, and pick Redeploy.
  4. Come back to this page and finish setup. Forgot your password? Use the same email: you keep all your cards. If someone else set up this Cardlake, use your own email: their account loses access.
  5. Delete CARDLE_SETUP_OPEN again and redeploy once more, so nobody else can do the same.
