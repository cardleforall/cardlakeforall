Updates

Get Cardlake updates

Your Cardlake doesn't update by itself. Turn on updates once, then get the latest version whenever you like. You keep all your cards: they live in your database, not in your code.

1. Turn on updates (once)

GitHub opens with the update file filled in. Click Commit changes, then Commit changes again. If GitHub says the file already exists, updates are already on.

Turn on updates

2. Get the latest version

Open Update Cardlake on GitHub and click Run workflow, then Run workflow again. Vercel deploys the new version a minute or two later.

If you've changed Cardlake's code yourself, the update stops rather than erase your changes, and says how to go ahead anyway.
